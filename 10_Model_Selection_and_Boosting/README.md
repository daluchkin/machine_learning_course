# Model Selection and XGBoost

These are my personal learning notes and experiments from the course [Machine Learning A-Z: AI, Python & R](https://www.udemy.com/course/machinelearning/) on Udemy. **Model Selection** techniques help optimize machine learning models by choosing the best-performing hyperparameters and evaluating performance using robust validation methods. Additionally, **XGBoost** is a powerful gradient boosting algorithm that enhances predictive accuracy.

- **Model Selection Techniques (Grid Search, k-Fold Cross Validation)** [>>](./01_Model_Selection_CV)  
  Grid Search can be combined with k-Fold Cross Validation to perform an exhaustive search over a predefined hyperparameter space while using k-folds to validate each parameter set. This ensures a more robust model selection process.

- **Extreme Gradient Boosting (XGBoost)** [>>](./02_XGBoost)  
  XGBoost is a scalable, high-performance gradient boosting algorithm that improves model accuracy through regularization, handling missing values, and optimized computational efficiency.
